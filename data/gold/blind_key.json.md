# data/gold/blind_key.json

The 40 same-paper panels of the reference set. Map from code (`B00`–`B39`) to `paper_id`, `year` and `review_ids`
(4 reviews each). 10 ICLR papers in each of 2018, 2022, 2024 and 2026. The reviews come from
`data/sample_reviews.parquet`.

## Make

No command in the repo makes it. It is a saved random draw.
